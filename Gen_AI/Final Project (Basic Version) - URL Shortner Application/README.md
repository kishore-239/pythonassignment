# URL Shortener Web Application

This project is a simple URL shortener built using Flask and SQLite.
Users can shorten long URLs and view their previously shortened URLs.

## Technologies Used
- Python
- Flask
- SQLAlchemy
- SQLite

## How to Run
1. Install dependencies  
   `pip install -r requirements.txt`

2. Run the application  
   `python app.py`

3. Open browser  
   `http://127.0.0.1:5000/`
